# ویجت تاریخ شمسی ویندوز

یک ویجت سبک دسکتاپ برای نمایش تاریخ شمسی امروز به زبان فارسی. برنامه با Python و Tkinter ساخته شده و در پایین سمت راست صفحه قرار می‌گیرد.

## امکانات

- نمایش روز، ماه و سال شمسی به فارسی
- نمایش تقویم کامل ماه با کلیک چپ
- مرور ماه‌های قبل و بعد با دکمه‌های بالای تقویم
- نمایش اختیاری بازه ماه و شماره روزهای میلادی از منوی تنظیمات
- نمایش تاریخ کامل شمسی و میلادی امروز و روز انتخاب‌شده
- اجرای اختیاری برنامه با شروع ویندوز
- مشخص‌کردن روز جاری در تقویم
- جابه‌جایی ویجت با کشیدن ماوس
- بستن برنامه با راست‌کلیک
- پشتیبانی از مقیاس‌بندی DPI ویندوز
- استفاده از فونت `Vazirmatn FD Medium` در صورت نصب بودن

## پیش‌نیازها

- Windows 10 یا 11
- Python 3

وابستگی‌ها را نصب کنید:

```powershell
python -m pip install -r requirements.txt
```

## اجرا

```powershell
python .\jalawidget.py
```

روی ویجت کلیک کنید تا تقویم ماه باز یا بسته شود. با کلیک روی هر روز، تاریخ کامل شمسی و میلادی آن را پایین تقویم ببینید. با دکمه‌های جهت‌دار بالای تقویم بین ماه‌ها جابه‌جا شوید. از دکمه چرخ‌دنده می‌توانید نمایش ماه میلادی و اجرای خودکار با شروع ویندوز را روشن یا خاموش کنید. برای تغییر محل ویجت، آن را بکشید و برای خروج روی آن راست‌کلیک کنید.

## ساخت فایل اجرایی

```powershell
python -m PyInstaller --clean --noconfirm .\jalawidget.spec
```

فایل اجرایی در مسیر زیر ساخته می‌شود:

```text
dist\jalawidget.exe
```

## ساختار پروژه

- `jalawidget.py`: کد اصلی رابط کاربری و تقویم شمسی
- `jalawidget.spec`: تنظیمات ساخت فایل اجرایی با PyInstaller
- `requirements.txt`: وابستگی‌های پروژه
- `AGENTS.md`: راهنمای مشارکت در مخزن
